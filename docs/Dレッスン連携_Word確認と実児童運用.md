# Dレッスン連携: Word確認と実児童運用

更新日: 2026-09-30

## 対象と本人確認

利用者が、ドリームズ21st若松高須西校への学習情報・成果物共有の説明と同意を確認し、校舎 `main` に加えて `wakamatsu-takasunishi` の連携も許可した。

指定されたローカルExcelの「児童番号」「児童名」「現行の合言葉」の列だけを使用する。過去の合言葉・合言葉案は使用しない。名簿の氏名/ふりがな、児童番号、校舎、内部学習ID、教室Authのメタデータと本人ログインを照合する。氏名・ふりがなはNFKC、空白除去、カタカナ/ひらがな統一で比較し、曖昧一致はしない。

通常ログインと教室ログインなど、複数のAuthが一人の学習IDに紐づいている場合がある。一人にAuthが一個という条件ではなく、今回使用する教室Authが当該児童だけにアクセスできることを確認する。不一致を通すために既存Auth、合言葉、取り組み記録を上書きしない。

実行結果と保留一覧はGit管理外の `output/lesson-workbook-operation-report.json` に保存する。元のExcelは変更しない。合言葉を画面、ログ、監査、Git、公開成果物に含めない。一時認証入力は適用完了時に削除する。

照合候補35名のうち18名はExcelの合言葉で本人ログインを確認できた。17名はExcelとAuthの合言葉が一致しない。利用者はSupabaseの現在の合言葉を保持する方針を指定したため、本人情報と既存の権限を照合し、メールを送らない管理用の一時セッションで自己データ取得・他児童拒否・Word連携を検証する。これはExcelの合言葉でログインできたことを意味しない。一致しない行の一覧を別に残し、元ExcelもAuthの合言葉も変更しない。在籍名簿36名の全員を連携済みとは扱わない。

## 操作の流れ

1. 連携済みの児童がWordで「先生にみてもらう」を選ぶ。
2. PDF・PNG・JPEG、8MB以下の作品を選び、職員への送信に同意して申請する。Word本体の操作を自動監視・自動保存するものではない。
3. Dサポートを開いている同事業所の職員に未確認件数を通知する。「申請を確認」または「学習管理 → Word確認」から開く。
4. 管理者または `review_learning_work` 権限を付与された管理職が作品を表示する。描画された作品を確認してチェックを入れ、承認または理由付きで差し戻す。
5. 承認はDレッスンDBのトランザクションでクリア、初回500コイン、取り組み履歴に反映する。再送で二重付与しない。
6. 児童はWord画面の更新ボタン、または表示中30秒ごとの取得で結果を受け取る。差し戻し理由を見て新しい版を再申請できる。

通知はアプリ表示中の通知帯で、60秒ごとと画面復帰時に更新する。アプリを閉じている場合のWeb Push・メール送信は今回の対象外。一般職員の閲覧は承認済み共有端末に限定し、承認権限は別に設定する。管理者・委任管理職の端末条件は既存の認可に従う。

## データと保護

- Dサポート: `lesson_child_links`、`lesson_link_audit`。職員の操作と利用者許可による移行を区別し、移行時に職員を偽装しない。
- Dレッスン: 校舎別 `lesson_support_scopes`、児童別 `lesson_support_students` の両方が必要。公開登録ユーザー・ゲスト・他校舎を自動で許可しない。
- `lesson_word_requests`: 申請の版、状態、コメント、ハッシュ、確認者、報酬。ブラウザーから直接読み書きできない。
- 成果物: 非公開Storage `lesson-word-work`。本人限定のアップロード先と職員向け120秒閲覧URLを発行する。別児童・別事業所の作品は取得できない。
- PDF.jsでページを描画し、文書のJavaScript・フォーム・リンク・埋め込み操作を実行しない。日本語CMapと標準フォントを静的アセットに同梱する。
- 作品を上書きせず、版とSHA-256を確認する。承認と同時に連携解除・期限終了・版変更があれば競合を返す。
- `supportWordRevision` で古い児童データによる報酬・クリアの上書きを拒否し、再読み込みを案内する。

## 保存期限・削除

- 送信準備の有効期限: 2時間。確認待ち: 30日で期限終了。
- 成果物: 承認・差し戻し後90日。期限終了した送信済み作品は提出から90日。未送信・取り消しファイルは次の定期処理で削除する。
- 毎日03:20 JSTに `word-review-cleanup` を実行する。定期実行間隔分の削除遅延があり、1回500件まで処理する。cron履歴とFunctionエラーを監視する。
- cron用の秘密値はVaultとFunction Secretsに保存する。無認証の削除呼び出しは拒否する。
- 児童データ削除時は共有許可を停止し、未確認申請を期限終了にして当該児童の作品と申請を削除する。Authのみ削除する場合は学習データを残し共有を停止する。
- 承認・監査メタデータとクリアの証跡は学習記録として保持する。成果物と同じ90日削除ではない。正式な業務記録へ自動変換・自動承認しない。

## 配備・検証

Dレッスン側 `student-word-review`、`support-word-review`、`word-review-cleanup`、既存 `admin-delete-auth-user` とDサポート側 `lesson-learning` を配備した。DB追加・cron設定も実接続済み。

架空児童の実接続で申請、非公開作品、受信一覧、差し戻し、再申請、承認、二重報酬拒否、古い児童保存拒否、解除、未認証・他範囲拒否を確認した。画面試験はモックでデスクトップ/390px幅、PDF描画、確認チェック、必須理由、児童切替、通信失敗と再送を確認した。実職員の端末での操作リハーサルは別途必要。

競合には `PT409` を使う。`40001` はPostgRESTで再試行され続けるため、業務上の版競合には使わない。

## 後続機能

学習範囲の割り当て、正式な支援記録への取り込み、児童管理全般の移管は後続段階。未移管のDレッスン管理機能は削除していない。ゲスト・公開ユーザー・未連携児童は既存のWord確認経路を維持する。
