# 記録入力の端末別表示（2026-10-26）

## 使い分け

- 自動：画面幅1199px以下、またはタッチ主体の端末では「タップ入力」、それ以外は「PC一覧」。入力画面の「表示方法」から手動で切り替えられる。
- PC一覧：児童切替を左側に置き、同じ場面の主要な選択項目を児童ごとの表で入力する。「個別入力」で表を収納し、その児童の詳細入力欄へ移動する。文章プレビューは必要時だけ開く。
- タップ入力：表情・準備を直接タップできるカードとして先に表示する。体調・服薬などは見出しから開く。閉じた項目も回答状況・注意事項を表示する。選択肢は短い説明を併記し、評価の全文も確認できる。
- 従来表示：既存の質問単位の表示へ戻す。表示方法は画面内だけの設定で、下書きに保存しない。

小学部・キャリアズの区分を児童選択、児童切替、PC一覧に表示する。登録区分と既存の学年判定を使用し、どちらもない場合は「区分未設定」とする。

## 入力・保存の不変条件

- 同一の質問・5段階評価・保存値を使用する。画面上の短縮表記を保存文面に転記しない。
- PC一覧の変更は明示選択した児童・項目のみ。未確認を回答済みとして扱わない。備考、詳細、Dレッスン実績、記録項目を維持する。
- 個別モジュールのIDが異なる場合は同じ質問として推測せず「個別入力で確認」とする。複数表情の旧記録や未知の選択肢は一覧で簡略化せず詳細で確認する。
- 既存の保存・下書き共有・競合確認・読み取り専用の処理、DBスキーマは変更しない。
- 児童タブの切替では表示位置を保持する。質問一覧や「個別入力」など明示的な移動操作では対象欄へ移動する。未入力への移動時は収納中の質問も開く。

## 検証

実際のRecordFormを架空の10児童・遮断した外部通信で表示し、PC、自動判定、手動切替、744/1133pxのタブレット、390pxのスマートフォンを確認する。

- `scripts/check-record-device-presentation-ui.mjs`：一覧入力、個別入力への移動、回答保持、児童切替、横はみ出し、44px以上のタップ領域。
- `scripts/check-record-tablet-ui.mjs`：既存の児童切替と表示位置保持。
- `scripts/check-record-draft-sync-ui.mjs`：別端末、オフライン復帰、競合時の確認。
- `scripts/check-record-save-recovery-ui.mjs`：保存復旧と上書き比較。
- `scripts/check-record-entry-ui.mjs` / `scripts/check-record-child-takeover-ui.mjs`：入力再開・児童引継ぎ。
- `tests/record-device-presentation.test.mjs`：対象値だけの更新、未確認・旧記録保持、短縮表示、編集制限。

ブラウザー版操作マニュアルの「様子・活動・宿題の記録を入力する」に表示方法を追記。配布PDFは従来版のままと明記する。
