# ホーム・メニュー・設定のUI整理

## 変更内容

- ホームに機能名・目的の検索と「当日の対応」「予定・送迎」「記録・児童」「共有・連絡」の絞り込みを追加。
- 広い画面ではホームを3列に配置。狭い画面では2列・1列に切り替え、ボタンの読みやすさを調整。
- ホームの業務メニューとハンバーガーメニューで名称・表示順・非表示設定を共通化。メニューIDと保存形式は変更なし。
- ヘッダーとハンバーガーメニューに現在の画面を表示。メニュー内検索、Escで閉じる操作、Tabでのフォーカス移動を改善。
- 設定を「事業所・送迎」「職員・運営」「記録作成」に分類し、検索を追加。「送迎の基本時刻・地点・エリア」から退所時刻などへ移動。

ホーム上部の「記録を始める／再開」「当日の送迎」と要確認アラートは固定のショートカットです。メニューの非表示設定とは別に表示します。非表示はアクセス権の変更ではありません。

## 運用前の確認

1. ホームで「下校」「シフト」「PDF」を検索し、該当する機能へ移動できることを確認。
2. 分類ボタンを切り替え、対象の機能のみが表示されることを確認。検索で見つからない場合は「絞り込みを解除」。
3. 「画面メニュー → 自分のメニューを編集」で順序・表示を変更して保存。ホームの業務メニューにも反映されることを確認。
4. 本日の業務・出勤予定・共有・連絡を開き、ヘッダーの画面名とメニューの「表示中」が一致することを確認。
5. 設定で「退所 時刻」を検索し、基本時刻の画面を開く。「設定一覧に戻る」で検索条件が保持されることを確認。確認だけの場合は時刻を保存しない。
6. 管理者・児発管・指導員で、それぞれ従来の権限に応じた設定だけが表示されることを確認。
7. スマートフォン・タブレットの縦横で、検索欄・カード・ボタンが画面外に切れないことを確認。

## ローカル確認結果（2026-09-09）

- `npm.cmd run check`：型チェック、46件のテスト、製品ビルド成功。
- Playwright：実際のホームをローカル試用モードで検証。設定・メニュー設定は同じ実装を固定のテスト職員・権限で表示し検証。
- 画面幅1440 / 1180 / 820 / 390 / 320pxでホーム・設定のレイアウトを確認。
- 順序・非表示の共通化、非表示項目が検索で復活しないこと、現在地表示、設定の検索と戻る操作、権限別表示、Esc・Tab操作を確認。
- 画像・ブラウザー確認スクリプトはGit管理外の `output/playwright/ui-*` に出力。
