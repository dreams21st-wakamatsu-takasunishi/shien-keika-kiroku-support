# 指導案を見ながら交通費を計算する

- 指導案の「交通費を計算」から、移動可能な小窓を開く。別画面への遷移や未保存指導案の置き換えは行わない。
- 見出しをドラッグ、または見出しにフォーカスして矢印キーで移動できる。拡大・小窓へ戻す・閉じるに対応。
- 距離・単価・児童数を入力する。車両、追加費用、端数処理は収納した欄から変更する。元の計算式と結果コピーを共用。
- 計算状態は既存の職員・事業所別のタブ内保持と同じ範囲。小窓を閉じて再表示しても入力が残る。別のユーザーへは引き継がない。
- 指導案の項目や計算結果を相互に自動上書きしない。人数等の自由記載を数字へ推測変換しない。
- 小窓から印刷は行わず、指導案印刷にも小窓は含めない。通常の交通費計算ページの印刷は従来どおり。
- 小窓を開いても指導案の未保存警告・明示保存・閲覧権限は変更しない。

検証：`check-activity-traffic-window-ui.mjs`（22項目、架空データのみ）、`check-activity-unload-ui.mjs`（34項目、標準のブラウザー離脱警告）、`verify-companion-training-release.mjs`（公開アセットのみ）。
