# スピード入力試験向けオリジナル模擬問題

作成日: 2026-10-19

同日追記: 校舎の二重管理を整理し、ユーザー承認により若松高須西校（wakamatsu-takasunishi）にも同じ固定IDの10題を追加した。若松高須西校で従来使われていた全体共通教材を引き継ぎ、元の課題・学習履歴は変更していない。後述のadd-speed-input-practice.mjsは初回の本校向け追加用であり、正式校舎への展開はreconcile-lesson-campus.mjsを使用する。本校側の21題はそのまま保持している。

既存の第81〜84回の登録課題を参照し、制限時間、難度、文章量、段落・数字・漢字変換の練習形式を合わせた。既存本文の改変や抜粋ではなく、新規に執筆した練習用文章であり、公式過去問・予想問題・公式採点基準ではない。内容中の施設や活動の事例は説明用で、実在の施設の実績を示すものではない。

## ファイルと検証

- `speed-input-mock-20261019.mjs`: 編集可能な原稿。登録済み過去問の本文は含まない。
- `speed-input-mock-20261019.json`: Dレッスンの既存課題形式に合わせた登録データ。既存IDを使い回さず、固定の新規IDを10件用意した。
- 読み仮名は隔離したkuromoji 0.1.2の辞書を基に生成し、文脈依存の「一人」「一冊」「一か所」「手当たり次第」「札」「角」などを確認・補正した。通常のアプリ依存関係にはライブラリを追加しない。

検証コマンド（Dサポートのルート）:

```powershell
node scripts/check-speed-input-practice.mjs
node scripts/check-speed-input-practice-ui.mjs --cli <Playwright CLIのパス>
node scripts/add-speed-input-practice.mjs --rollback-test
```

画面検証はDレッスンの開発サーバー localhost:5178 と架空ユーザーだけを使う。フィクスチャはテスト時にDレッスンの無視対象 output フォルダーへコピーする。本番通信を遮断し、成績は保存しない。10題すべての選択、開始、本文全文、読み仮名の切り替え、入力位置の追従を検査する。

## 追加の範囲と保護

登録先は既存過去問4題がある校舎 main の `lesson_campus_content`（`data_table=user_data`）のみ。全体共通設定、他校舎、実児童のJSON、Auth、学習履歴を変更しない。

`add-speed-input-practice.mjs --apply` はユーザー承認に基づくCLIバッチであり、実職員のログイン操作として偽装しない。アプリと同じ校舎単位のアドバイザリーロックに加えて行ロック、事業所・接続先・有効許可・revision・fingerprintを照合する。10題を一つのトランザクションで末尾へ追加し、元の全課題の内容と順番、ごほうび、他校舎、全体設定が不変であることを検証する。既存参照との50文字連続一致も検査する。

登録前の教材スナップショットと、実行ID・結果・教材ハッシュを含むレポートは無視対象の output 内に保存する。実児童や職員の情報は含めない。学習履歴の表は参照もしない。再実行は10件すべてが同内容で登録済みなら追加せずに終了し、一部のみ・別内容なら停止する。取得した古い一覧で、新しい編集を上書きしない。

クラウド教材の追加なので、アプリのプログラム再公開は不要。学習側は再読み込みまたは再ログインして課題一覧を取得する。
