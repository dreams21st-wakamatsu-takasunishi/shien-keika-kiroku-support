# 交通費計算

ホーム／画面メニューの「交通費計算」から利用します。
Google Maps APIは呼び出さず、距離を手動入力します。

## 計算ルール

- 各車の費用＝往復距離÷燃費×ガソリン単価。
- チェックした車両のみ合計。同じ往復距離を走る前提。
- 追加費用は「全車合計」なら1回だけ加算、「1台あたり」なら使用台数を掛ける。
- 児童1人あたり＝総費用÷利用児童数。職員は人数に含めない。
- 途中の計算は丸めず、表示のみ小数第2位まで。集金目安は選択した端数処理を適用。
- 初期値は提供Excelのフリード13.16、スペイド12.94、ムーヴ16.83、アクア21km/L、ガソリン160円/L。単価・燃費は現在値の保証ではない。
- Excelの `SUM((C3:C5)+D2)` はD2を3回加算する。これに対応するのは「1台あたり」。全車合計として入力する場合は1回のみ加算する。

## 図解マニュアル

ページ上部の「距離の調べ方（図解）」から、[図解マニュアル](../public/manuals/traffic-cost/index.html)を別タブで開けます。
印刷ボタンからPDFとして保存できます。提供画像は原本を変更せずコピーして使用。
ダウンロード用のA4・3ページ版PDFも同じマニュアルに用意しています。全ページを画像へ展開して、文字・図・改ページを確認済みです。
距離欄の画像素材はないため、出発地・目的地および距離の読み方は「模式図」と明示しています。
Googleの手順は[公式ヘルプ](https://support.google.com/maps/answer/144339?co=GENIE.Platform%3DDesktop&hl=ja)を参照。

## 入力保持

入力はsessionStorageに、事業所・ログインユーザー別のキーで保持。
同じタブでの画面移動・再読み込みに対応し、サーバーには保存しない。
ログアウト時に当計算のタブ内保存を消去。別端末への共有や履歴台帳は含まない。

## 確認

- Excel「1014 グルーンわかまつ」の8.5km・160円・8名・2台と一致。
- Excel「0318 もじ少年自然の家」の40km・150円・8名・3台・追加520円/台と一致。
- 4台使用・往復距離入力・燃費変更・端数処理・不正入力を自動テスト。
- 画面で入力に追従した計算、0名・空欄での結果非表示、車両選択、入力保持、リセット、コピー、印刷、スマートフォン幅を確認。
- メニューの表示非表示・並べ替え保存には追加マイグレーション `202610020001_traffic_cost_menu.sql` を適用。
