# Dレッスン手動入力・過去実績・朝礼振り返り

## 手動入力

支援記録の「パソコン → Dレッスン」で、従来の6種類の練習を複数選択する。
自動実績と同じ分類の選択は書き出し時だけ重複を抑える。選択自体は保持され、実績を除いても手入力は残る。
既存の課題名・完了状況・測定値付き手入力は「保存済みの詳細手入力」から編集できる。既存データの移行や削除は行わない。

## 過去の実績

「日付を選んで実績を取得・追加」を開き、実績の取得日を選択する。
入力中の支援記録日を含む、その3日前までの4日間が対象（カレンダー日単位）。
例：10月8日の記録には10月5日〜8日の実績を取得できる。
取得後、実績を選び、児童・実施日・内容を確認して追加する。正式な支援記録保存は別操作。
当日以外の実績は書き出しにも実際の実施日を明記し、当日に実施したように表現しない。
自動反映の取得対象は従来どおり支援記録日当日のみ。

証跡の `date` は実際の実施日。過去実績の `recordDate` は取り込み先の記録日。
古い証跡では `date` を取り込み先として扱う。記録日・児童・事業所を変更すると保存前確認で不一致を検知する。
連携情報と選択実績は追加直前にも再取得して確認する。日付変更で確認状態を解除し、変更前の遅延応答を採用しない。
履歴なしは未実施の証明ではない。Dレッスン側に履歴が保存されていなければ復元できない。

## 朝礼

朝礼の入力欄に並べて「前回の支援の振り返り」を表示する。携帯画面では入力欄の下に表示する。
朝礼日が月曜の場合は金曜、それ以外は前日を対象とする。祝日・欠席等による自動的な前日探索は行わない。
現在の事業所で読み込み済みの支援記録と児童一覧だけを使用し、別事業所や外部AIへの追加送信は行わない。
様子、特記、職員備考などの記載から最大3項目の要点を抜粋する。否定文を途中で切らず、推測した評価を付け加えない。
「元の記録を確認」で出欠・取り組みなどの抜粋元も展開できる。記録者と確認状態を表示する。
複数記録は個別に表示し、記録がない児童は「この日の支援記録はありません。」と表示する。
検索や展開で朝礼入力欄を置き換えたり、自動転記したりしない。
