# Dレッスン連携: 支援経過記録への実績取り込み

更新日: 2026-10-01

## 操作と対象

職員ログインとクラウド接続のあるDサポートで、記録作成の「パソコン取り組み内容」から実績を取得する。入力中の児童・記録日で履歴を取得し、必要な実績を個別選択する。「児童・日付・内容を確認しました」の確認後に追加する。正式な支援経過記録の保存・確認は既存の手順のまま。

標準の平日・休日フォーマットと統合フォーマットのパソコン項目など、`pc_activities` 型の質問が対象。自由記入だけの独自質問や3コマ目の旧形式には自動挿入しない。未連携児童、ゲスト・公開登録ユーザー、クラウド未接続、個人送迎限定画面は対象外。閲覧専用下書きや引継ぎによってロックされた下書きでは取得・追加・削除できない。

既存の学習履歴閲覧と同じ事業所・職員・承認済み端末の条件を使う。課題管理権限は不要だが、閲覧権限を広げる実装ではない。取得直前・追加直前に現在の連携を確認し、追加前に履歴を再取得する。解除・変更された連携、変化した選択実績は再取得・再確認が必要。

## 自動入力しない内容

- 姿勢、タイピングの指使い、表情、自力での取り組み、必要だった支援、職員の働きかけ、目標達成・評価。
- 履歴がないことを根拠にした「未実施」判断。
- 課題を指定しただけの内容や、選択していない実績。
- Word成果物の本文・画像・ファイル。今回の取り込みは学習実績の限定項目のみ。

元の手入力、備考、文章入力模擬試験の文字数・回数などは保持する。旧形式の手入力だけだった項目は「既存の手入力」として残し、編集可能にする。Dレッスンの実績は事実として「実績：時刻 / タイトル / 内容 / 数量」の形式で追加し、既存の記録プレビュー・文章生成・印刷へ渡す。姿勢・支援内容などは職員が別途入力する。

## データと保存

`SectionFieldAnswer.nestedDetails.dLessonHistoryEvidence` に版1のJSON文字列として記録し、下書きと正式記録の既存保存経路に載せる。実績ID、時刻、分野、タイトル、内容、数量、Dサポート児童ID・事業所・記録日、学習ID・校舎・テーブル・プロジェクト、連携ID・版、確認職員Auth ID・確認日時だけを保持する。メール、合言葉、生年月日、児童JSON全体は複製しない。確認情報は職員の操作を記録するメタデータであり、サーバー署名や新しい監査台帳ではない。

同じ学習アカウント・実績IDは同じ項目に重ねて追加しない。1項目につき50件まで。異なるコマの項目同士は自動で統合しないため、職員はそのコマに該当する履歴だけを選択する。取込後に記録児童・日付・事業所が一致しなくなった場合やJSON形式が不正な場合は、既存の保存前点検でエラーにして正式保存を停止する。

「取り込み実績を除く」は当該項目の取り込み分を取り除き、手入力・備考を残す。保存済みの写しは元データの修正・削除・連携解除に追従して自動削除しない。Dサポートの支援記録・下書きと同じ閲覧範囲・保持・削除手順で扱う。既存の下書き自動保存は行うが、正式記録は自動確定しない。

## 配備と検証

フロントエンドのみの変更。新しいDBテーブル、権限変更、SQL適用、Function再デプロイは不要。既存の `lesson-learning` の履歴APIと `save_record_draft_guarded` を使う。

- `npm.cmd run lint` / `npm.cmd test` / `npm.cmd run build`。
- Viteを3014番で起動し、`node scripts/check-lesson-record-import-ui.mjs --cli <Playwright CLIのplaywright-cli.js絶対パス>`。親の記録作成画面を含む架空データ・APIモックで、選択・確認・下書き反映・手入力保持・重複防止・実績削除・解除/変更・児童/日付切替・取得失敗/再取得・閲覧専用・保存前点検・390px/1280px表示を確認する。Supabase通信はモック以外遮断し、試験ページは公開ビルドに含めない。
- `node --import tsx scripts/check-lesson-record-import-live.mjs --run-fictional-test`。既存の許可済み事業所・本校で隔離した架空職員・児童・連携・下書きを作り、実履歴API、選択した実績の保存RPC/再読込、重複防止、許可解除時の拒否を確認し、試験データを削除する。実児童の情報・連携・取り組みを変更しない。終了時に既存学習データのハッシュ一致を確認する。

実職員の公開画面での入力・保存リハーサルとは区別する。源泉は保存済み履歴のみで、完全な全活動記録を保証しない。
