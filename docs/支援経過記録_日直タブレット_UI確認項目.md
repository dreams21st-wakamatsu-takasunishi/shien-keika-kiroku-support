# 支援経過記録：日直のタブレット記録

## 変更内容

- 児童選択・入力中の児童タブを、小学部は青、キャリアズは紫で表示。色だけでなく部門名も表示する。
- 部門・名前で絞り込み、表示中の児童を部門単位でまとめて選択できる。他職員が入力中の児童はまとめ選択でも除外する。
- 日直用の直接入力を初期表示とし、出欠・表情・疲れ・準備・声掛けへの反応・服薬を折り畳まずに表示する。
- 評価は数字だけでなく短い意味を表示し、選択した正式な基準も表示する。全基準は「選択肢の詳しい基準」で確認できる。
- 学習・パソコン時の姿勢は、背すじと足の選択肢を直接表示する。
- 「同じ項目で次の児童」で、同じ観察項目を続けて確認できる。通常の児童タブは従来どおり、その児童が最後に開いていた画面へ戻る。
- 対象児童に同じ学習・活動項目がない場合は、理由を表示して項目選択へ移動する。項目や回答を勝手に作成・複製しない。同種の項目が複数ある場合は同じ順番の項目を対象とする。
- 画面下の移動・確認ボタンをスクロール中も表示する。既定位置のクイックメモと重ならない余白を設ける。
- 「項目を開いて記録」に切り替えると従来の折り畳み入力も使用できる。

## 部門の判定

児童台帳の小学部／キャリアズの登録（送迎で使用している `transportProgram`）を優先する。未登録の場合は記録日時点の学年を参照し、既存の部門判定を使用する。年齢だけで登録済みのキャリアズ児童を小学部へ変更しない。

## 記録の質・互換性

- 保存する評価値・詳細データ・文章生成の方式は変更しない。短いラベルは表示専用で、保存時に元の正式な選択肢を使用する。
- 小学部・キャリアズで、準備・学習・活動の観察例を調整する。独自の質問は元の文言を使用する。
- 観察メモでは「事実 → 行った支援 → その後の変化」を促す。本人の発言・時刻・普段との違いも必要に応じて残す。
- 見ていない内容は「未確認として保留」にできる。自動回答はしない。保存前の点検で未回答・保留を引き続き確認する。
- 宿題の教材・検定・パソコン課題・食事・ABC等の詳しい入力、申し送り、児童情報、保存前点検、上書き確認を維持する。
- 回答した学習項目・おやつに保留状態が残ってしまう不具合も修正する。
- 児童切替時にメモ欄の開閉状態が別児童に持ち越されないようにし、入力中のメモ見出しの変化による位置移動を抑える。
