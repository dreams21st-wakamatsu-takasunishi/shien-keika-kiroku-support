# Dレッスン連携: 課題指定

更新日: 2026-10-01

## 操作と範囲

Dサポートの「学習管理 → 課題の指定」で児童を選び、分野・課題名・取り組む内容・開始日・終了日を保存する。分野はマウス、キーボード、文章入力、Word、ビジョン、タイピングゲーム。管理者、または学習連携管理権限を委任された管理職だけが追加・編集・停止できる。一般職員は既存の事業所・承認済み共有端末の条件で閲覧のみ可能。

「対象児童」の選択欄をタブ直下に表示する。管理権限があり、連携済み児童に課題がまだない場合は入力フォームを自動表示する。既存課題がある場合は「課題を追加」、各課題の「編集」「停止」から操作する。閲覧権限の場合は理由を明示し、未連携・サーバー未設定・通信失敗は別の状態として表示する。読み込み中の児童選択で連携一覧の取得を取り消さない。

設定項目名は「学習連携・課題管理」（内部キー `manage_learning_links`）。児発管・教室長に自動付与する権限ではなく、管理者による委任が必要。表示改善に伴う既存権限・実児童連携の変更は行わない。

教室児童のDレッスンホームに「先生からのかだい」を表示し、対象分野の既存メニューへ移動できる。ホーム表示中30秒ごと、画面復帰時、更新ボタンで再取得する。日本時間で期間内かつ有効な課題だけを表示する。ゲスト・公開登録ユーザーは対象外。

これは課題の案内であり、指定外の練習を禁止する機能ではない。M-1などの具体的範囲は課題名・内容に指定する。ボタンは既存の分野メニューを開き、ステージの前提条件や解放順を迂回しない。クリア・コイン・成績・取り組み記録を変更せず、課題の表示やボタン押下を達成の証拠としない。ステージID付きカタログ、範囲外開始の禁止、達成との自動照合は後続段階。

## データと安全性

- Dレッスンの `lesson_learning_tasks` と `lesson_learning_task_audit` に分離保存。児童のJSONへ混ぜない。
- ブラウザーのテーブル直接操作・学生の課題作成は拒否。職員の `lesson-learning` が現在のAuth、事業所、端末、管理権限とDサポート連携を確認する。
- サーバー専用秘密値で `support-learning-tasks` を呼び、source側の校舎許可・児童別許可・連携ID・児童ID・現在の教室データを照合する。
- 保存RPCでも許可行をロックして再確認する。更新版競合はPT409、同一保存の再送は二重登録・二重監査にしない。
- 学生用 `student-learning-tasks` は本人Authと学生アクセス行だけを受け付ける。校舎・児童別共有許可・連携が解除されると新たな取得では表示しない。既存画面での反映は次の再取得まで最大30秒程度。
- 本文はプレーンテキストで描画。課題名80文字、内容500文字、期間90日以内、有効課題20件まで。管理一覧は有効分を優先し直近100件まで。
- 監査には保存した版と操作職員を残す。課題の停止は削除ではない。現段階では課題・監査は学習管理メタデータとして保持し、期間終了だけでは自動削除しない。
- 学習データ削除では課題と当該監査を削除する。児童別許可行の削除も課題・監査に連鎖する。Authのみ削除する場合は共有許可停止で児童向け表示を停止し、学習データ・課題は保持する。

## 配備と検証

source側SQL `supabase/sql/support_learning_tasks.sql`、Function `support-learning-tasks` / `student-learning-tasks`、Dサポート `lesson-learning`、児童削除 `admin-delete-auth-user` を配備した。フロントエンドは両アプリの通常のGitHub Pages公開手順で更新する。

ローカル型検査・単体テストとメモリー上のPostgreSQLで、期間・分野・文字数・二重保存・版競合・事業所/児童範囲・直接読み書き拒否・解除・学習データ不変を確認した。架空データの画面試験で追加・編集と390px/1280px幅の表示、児童の分野移動を確認した。

親画面を含むブラウザー回帰試験は、Viteを起動して `node scripts/check-lesson-task-ui.mjs --cli <Playwright CLIのplaywright-cli.js絶対パス>` で実行する。既定URLは `http://localhost:3014/tests/fixtures/lesson-learning.html`（`--url` でlocalhostの試験ページだけ変更可能）。架空児童・APIモックで入力・保存・編集・停止、児童/職員切替の遅延応答、読み込み中の選択、閲覧権限、未連携、未設定、一覧/課題の取得失敗と再取得、390px/1280px表示を検証する。Supabase宛通信は遮断し、試験ページ・APIモックは公開ビルドへ含めない。実職員ログインの公開画面確認とは区別する。

`node scripts/check-learning-tasks-live.mjs --run-fictional-test` は既存の許可済み本校・指定事業所で隔離した架空名簿・児童Auth・一時試験職員と共有端末を作り、職員APIと学生APIを実接続確認して終了時に削除する。既存校舎許可・実児童連携を変更しない。実接続で保存、学生表示、他児童拒否、一般職員の閲覧のみ許可、停止・解除、再送・競合を確認し、試験データ削除後の既存学習データのハッシュ一致を確認した。実職員の端末での運用リハーサルとは区別する。

## 残る統合

支援経過記録への確認付き下書き取り込みは実装済み（`Dレッスン連携_記録取り込み.md` 参照）。学習状況の集計、ステージ単位の課題/制限、名簿からのアカウント発行、教材・報酬・バックアップ等の管理移管は未完了。Dレッスンの未移管管理機能は引き続き維持する。
