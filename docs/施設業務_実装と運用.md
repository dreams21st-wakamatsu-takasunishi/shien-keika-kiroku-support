# 施設業務

ホーム・ハンバーガーメニューの「施設業務」から利用します。事業所共有端末の職員、管理者・児発管向けです。個人端末の送迎専用モードには表示しません。

## 日常点検

- 日付・確認者を入力し、各項目を「問題なし」「要対応」「対象外」で確認します。
- 要対応にはメモを入力。対応済みをチェックするまで、確認完了後も「対応残り」が表示されます。
- 項目を追加・削除・修正し、「ひな形として再利用」で事業所の点検表を作れます。複製時は確認者・結果・対応メモをリセットします。
- 初期項目は編集可能な例であり、法定点検を網羅したものではありません。事業所の手順と照合してください。

## 備品・補充

- 品名・分類・単位・保管場所・補充目安を登録します。新規登録時の数量は0です。
- 初期在庫は「入庫」、使用分は「使用」、実数との差は「調整」で入力します。理由必須、整数数量です。
- 在庫が補充目安以下の備品を強調。「補充を依頼する」を保存すると職員間で共有できます。
- 入庫後に補充目安を上回った場合、補充依頼を自動解除します。発注・外部への通知は行いません。
- 数量と履歴を一括更新します。他職員による先行更新は競合として停止し、同一通信の再送は二重計上しません。
- 使用しない備品は「保管」とし、履歴を残します。履歴表示は備品ごと最新100件、台帳は最大1,000件です。

## おたより

- あいさつ・本文・予定・持ち物・問い合わせ先を入力し、プレビュー・文章コピー・印刷／PDF保存できます。
- 文例と保存済みひな形から複製可能です。児童名・写真・支援記録の自動取り込み、メール等の配信はありません。
- 配布前に個人情報、内容、配布対象を確認してください。

## 保存・権限

- 手動保存です。未保存の入力は事業所・ログインユーザー・機能ごとに、そのブラウザタブのsessionStorageへ保持します。共有は保存後。ログアウトで下書きを消去します。
- 別画面・別機能への切替時に未保存確認。再読み込みにも警告します。ブラウザ保存不可の場合は警告を表示します。
- サーバー保存は事業所ごとに分離、共有端末制限、更新履歴監査、世代番号による競合検出があります。削除でなく保管を用います。
- 点検・おたよりの一覧は各最新500件です。自動削除はありません。実際の保存期間は事業所の運用で定めてください。
- 既存の児童記録、予定、申し送りを自動変更しません。必要な共有文は文章コピーを利用できます。

## 検証の区別

型チェック・139件の自動テスト・本番ビルドを確認済みです。分離されたPostgreSQL環境でSQL・権限・数量更新・二重計上防止を確認しました。この環境の職員／端末関数は検証用代替であり、本番のログイン・登録端末での動作確認と同一ではありません。

ブラウザのローカル試用では、点検完了の入力検証、要対応表示、ひな形、機能／画面切替後の下書き復元、先行更新時の競合と入力保持、備品の入庫・使用・調整・補充依頼・保管と履歴保持を確認しました。PC幅1,440px・スマートフォン幅390pxで横はみ出しがないこと、点検表とおたよりのPDF、長文おたよりの2ページ印刷を確認しました。

公開後は共有端末の実アカウントで保存・再表示を確認してください。
