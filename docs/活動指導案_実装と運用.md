# 活動・指導案

ホームと画面メニューに「活動・指導案」を追加。
セル操作をせず、ひな形選択・入力・保存・印刷で業務を完結する。

## 今回の範囲

- 工作・運動・調理・外出の初期ひな形、空白からの作成。
- ねらい、対象・人数、場所、担当、活動の流れ。所要分数から開始・終了時刻を計算。
- 準備物・数量・担当とチェック、役割分担、参加しやすくする配慮、安全・緊急時対応。
- 活動全体の振り返り、次回に活かすこと。
- 事業所内の案共有、検索、複製、自作ひな形、保管、文章コピー、印刷・PDF保存。
- 交通費計算・業務カレンダーへの移動。金額や予定は自動転記しない。

ひな形は入力のたたき台であり、活動の安全性や個別児童への適合性を保証するものではない。
個別支援計画や支援経過記録へ、自動で内容を作成・上書きしない。

## 保存と権限

運用環境の保存先は `activity_plans`。組織単位で分離し、事業所共有端末で職員が共有する。
管理者・児発管の既存端末権限は継承する。個人端末の送迎専用モードには表示しない。
保存は明示操作。未保存の入力は組織・ユーザー別にこのタブのsessionStorageへ保持し、ログアウト時に除去する。
保存時にrevisionを比較し、他職員の先行保存を黙って上書きしない。履歴監査ログを記録。
削除でなく「保管」に移す。試用モードのみlocalStorageに保存する。
初期一覧は最新500件。検索は取得済み一覧を対象にする。

## 本番反映の順序

1. `npx.cmd supabase db push` で `202610040001_activity_plans.sql` を適用。
2. 型検査・テスト・ビルドを確認してフロントを公開。
3. 共有端末の指導員と管理者で案の作成・保存・再表示・競合・メニュー設定を確認。
4. 個人端末と別組織では閲覧・更新できないことを確認。

本機能に新しいEdge Functionや外部AIサービス、地図APIは不要。

## 開発確認

型検査・129件のテスト、試用モードで作成→準備チェック→振り返り→保存→複製→未保存入力の画面間復元を確認。
PC/スマートフォン幅で横にはみ出さないこと、印刷用PDFの見た目を確認。
隔離したPGliteでSQL適用・保存・revision競合・監査・組織分離・個人端末/匿名/削除制限を実行確認。
このSQLテストの認証・端末判定はスタブであり、本番の端末登録・実アカウントの検証を代替しない。
