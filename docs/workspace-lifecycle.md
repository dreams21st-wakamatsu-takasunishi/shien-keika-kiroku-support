# 削除・復元・申請取り下げ

## 保存済みデータの削除

管理者・児発管が、保存したデータを開いて「削除（復元可能）」を選びます。未保存の編集がある場合は、先に保存または破棄してください。個人端末の送迎専用モードでは利用できません。

対象は会議支援（会議メモを含む）、朝礼記録、申し送り、活動・指導案とそのテンプレート、点検・おたよりとそのテンプレート、備品・消耗品です。「保管」とは別の操作です。

削除は通常の一覧から非表示にする処理です。本文・関連履歴・備品の在庫数や入出庫履歴は消去しません。承認済み会議の本文も変更しません。別の職員が更新した場合は処理を止めるため、一覧を更新して内容を確認してください。

## 間違えて削除した場合

「設定 → データの復元 → 削除済みデータ」で、種類・削除日時・削除者を確認し、「復元」を選びます。元の画面の一覧を更新すると再び開けます。保管済みだったデータは保管状態に戻ります。各種類の最新200件を表示します。

朝礼記録を削除した際は、画面にある入力本文を残して編集を停止します。復元してから再開してください。古い画面から保存しても、削除済みの本文を上書きして復活させることはできません。

完全消去や自動削除は行いません。削除・復元した日時と操作職員の履歴を残します。

## 申請の取り下げ

「出勤予定 → 自分の申請の取り下げ・履歴」を開きます。自分が提出した申請中のシフト希望・打刻修正申請に「取り下げ」が表示されます。ログイン職員と本人の職員名簿の両方が一致している必要があります。

承認・却下済みや他職員の申請は取り下げできません。取り下げは勤務予定・打刻実績を変更しません。取り下げた申請の履歴を残し、元の申請内容も非公開の履歴として保持します。再申請は通常の提出操作から行ってください。

古い管理者画面から、取り下げ済み申請を再び承認することはできません。一覧を更新してください。
