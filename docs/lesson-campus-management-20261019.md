# Dレッスン校舎・登録管理の整理（2026-10-19）

- 校舎名はDレッスンの共通台帳lesson_campusesから取得する。若松高須西校の既存コードを維持し、本校mainを同名へ改名したり児童を移動・統合しない。
- 新規登録を許可された担当校舎が1件なら選択欄を省略し、登録先名を明示する。本校への新規作成は停止するが、既存の未確定登録の再開は保持する。
- 若松高須西校の校舎単位の学習管理接続と模擬問題10題の追加はユーザーが明示承認。既存の児童ごとの共有先・Dサポート児童リンクは変更しない。
- 教材は、専用教材を作る前に使用していた全体共通一覧を引き継ぎ、固定IDの10題を追加する。既存の内容と順番を保持し、本校教材・他校舎・公開ユーザーの教材を変更しない。同じIDの本文が異なる場合は中止する。
- scripts/reconcile-lesson-campus.mjsの--rollback-testと--applyを使用する。既存児童JSON、Auth、本校教材、共有許可のハッシュ不変を確認し、レポートだけをoutputへ保存する。児童名やパスワードをレポートへ出さない。
- scripts/check-student-management-live.mjs --run-fictional-testは隔離した架空校舎・先生・児童・Authのみを作成して削除する。本番の実児童をテスト操作しない。
- 児童の所属確認はDレッスンの認証・校舎対応に依拠する。所属・Authが照合できない既存データは推測で修復せず、「校舎設定要確認」として管理者の確認対象にする。
