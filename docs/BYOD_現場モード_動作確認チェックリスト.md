# BYOD・現場モード 動作確認チェックリスト

対象：個人端末用の現場モード、クラウド限定保存、バックグラウンド遮蔽、復帰時の本人確認

## 事前準備

- 管理者または児発管で、検証用職員に個人PINを設定する。
- 検証端末を個人端末として承認し、「現場モード」を指定する。
- 通常端末との差を確認するため、事業所管理端末も1台用意する。
- 実在児童の情報を使わず、検証用児童・検証用記録で確認する。

## 1. 現場モードへのログイン

- [ ] ログイン画面を開くと、職員IDログインが最初に表示される。
- [ ] メールアドレス入力欄は最初から展開されず、「管理者・児発管のメールログイン」を選ぶと表示される。
- [ ] 初回の職員IDログインでは、事業所コード・職員ID・パスワードを入力する。
- [ ] ログイン成功後、次回は事業所コードがコンパクトに表示され、職員ID・パスワードだけでログインできる。
- [ ] 記憶された事業所コードを「変更」から修正できる。
- [ ] 職員IDとパスワードでログインした直後は、同じタイミングで個人PINを重ねて要求されない。
- [ ] 保存済みセッションからアプリを再開した場合は、児童情報が表示される前に本人確認画面が表示される。
- [ ] ログイン中の職員名が固定表示され、別職員へ切り替えられない。
- [ ] 誤ったPINでは解除されない。
- [ ] 正しいPINでホーム画面へ進める。
- [ ] PIN未設定の職員は解除できず、管理者への設定依頼が表示される。
- [ ] 本人確認画面からログアウトできる。

## 2. バックグラウンドと復帰

- [ ] 児童情報を表示した状態で別アプリへ切り替えると、アプリ内容が保護画面へ置き換わる。
- [ ] 30秒未満で戻った場合、保護画面が消えて元の画面へ戻る。
- [ ] 30秒以上経過して戻った場合、本人確認画面が表示される。
- [ ] 正しいPINを入力すると、元の入力内容を保持したまま再開できる。
- [ ] 誤ったPINでは元画面を表示できない。
- [ ] 端末を画面ロックして30秒以上経過後に戻った場合も本人確認が必要になる。

## 3. 支援記録のクラウド限定保存

- [ ] 記録画面に「クラウド下書き自動保存」と表示される。
- [ ] 説明文に「端末内へ残さずクラウドだけに自動保存」と表示される。
- [ ] 入力後、別の承認済み端末から同じ下書きを確認できる。
- [ ] ページを再読み込みしても、クラウド保存済みの下書きから再開できる。
- [ ] 保存済み記録が記録一覧へ1件だけ登録され、二重保存されない。

## 4. クイックメモのクラウド限定保存

- [ ] クイックメモアイコンを画面の左上・右上・左下・右下へ移動できる。
- [ ] クイックメモアイコンを長押ししても、画面の文字選択やコピーメニューが表示されない。
- [ ] それぞれの位置でメモを開くと、現在のアイコン位置からメモが広がるように表示される。
- [ ] 移動前の古い位置から広がるような動きが残っていない。
- [ ] クイックメモに「クラウド保存・端末内保存なし」と表示される。
- [ ] 入力後に「保存済み」と表示される。
- [ ] 別の承認済み端末から同じ職員のメモを復元できる。
- [ ] 午前3時のリセットまたは手動削除後、別端末にも削除が反映される。

## 5. 記録項目の再開・新規追加

- [ ] 「何を記録しますか？」から学習を初めて選ぶと、確認画面を出さず学習入力へ進む。
- [ ] 学習を一部入力して項目選択へ戻り、もう一度学習を選ぶと、「入力内容は残っています」と確認画面が表示される。
- [ ] 既存の学習で「再開」を選ぶと、先ほどの入力内容を保ったまま続きから入力できる。
- [ ] 「新しい学習を追加」を選んだ場合のみ、2件目の学習入力が作成される。
- [ ] 学習が複数ある場合、どの学習を再開するか一覧から選べる。
- [ ] お昼ごはん・おやつは既存記録の再開のみ表示され、重複追加できない。
- [ ] キャンセルした場合、既存の入力内容と件数が変更されない。

## 6. オフライン時の安全動作

- [ ] 現場モード端末をオフラインにすると「端末内に保存しない」と表示される。
- [ ] オフライン状態で完成記録を保存すると、端末へ保存せずエラーを表示する。
- [ ] 「未送信○件」として新しい記録が追加されない。
- [ ] 通信復旧後、クラウド保存済み下書きを開いて保存できる。
- [ ] 通信が不安定な状態でも、保存ボタンを連打して二重登録されない。

## 7. 通常端末への影響確認

- [ ] 事業所管理端末では従来どおり端末内下書きが利用できる。
- [ ] 通常端末では短時間のバックグラウンド移行で本人確認を要求されない。
- [ ] 通常端末のオフライン再送キューが従来どおり動作する。
- [ ] 記録作成、記録一覧、引き継ぎ、クイックメモの基本操作に変化がない。

## 8. 管理者による端末停止

- [ ] 管理画面で個人端末を停止すると、対象端末が次回確認時にログアウトする。
- [ ] 停止後に同じ端末から再ログインしても利用できない。
- [ ] 他の承認済み端末には影響しない。

## 不具合報告時に記録する内容

- 発生日時
- 端末名・OS・ブラウザ
- 現場モードまたは通常モード
- オンラインまたはオフライン
- 操作した画面と直前の操作
- 表示されたエラーメッセージ
- 再現手順
- 児童名などの個人情報を含めないスクリーンショット
