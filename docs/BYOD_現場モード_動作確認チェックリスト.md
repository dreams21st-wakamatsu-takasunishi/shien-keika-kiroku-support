# BYOD・現場モード 動作確認チェックリスト（旧仕様）

2026年8月10日の方針変更により、個人端末では支援経過記録を入力しない仕様になりました。

以前の「個人端末で支援記録をクラウド限定保存する」確認項目は、現在の実装対象ではありません。個人端末は送迎専用、支援記録は事業所共有タブレットまたは管理用PCで行います。

現在の確認項目は、次のファイルを使用してください。

- [個人端末送迎モード・共有端末 動作確認チェックリスト](./個人端末送迎モード_動作確認チェックリスト.md)

旧仕様で実装したバックグラウンド遮蔽、30秒経過後の個人PIN再確認、端末内へ個人情報を保存しない保護処理は、送迎モードでも引き続き使用します。
