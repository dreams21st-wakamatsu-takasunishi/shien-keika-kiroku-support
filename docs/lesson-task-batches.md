# 第7実装単位: 校舎・学習グループでの課題一括指定

入口: Dサポート「学習管理 → 課題の指定 → まとめて指定」。既存の「児童ごと」の追加・編集・停止は維持する。

## 操作と範囲

- 有効に連携された名簿の児童を、Dレッスンの校舎ID・学習グループ・児童名で絞り込み、チェックして選択する。名簿の学校や送迎グループを学習グループに転用しない。未連携・公開登録・ゲスト・許可範囲外は対象にしない。
- 表示中の選択・選択解除を用意する。絞り込みで隠れた選択も保持し、保存前の確認画面では全対象児童・所属・課題名・分野・ステージ・内容・期間を表示する。対象確認チェック後に作成する。確認画面を開いただけでは児童の課題を作成しない。
- 1操作で1〜100名、15分で新しい確認操作10件まで。対象一覧は500名までとし、超過は明示的に拒否する。対象外や未取得の児童を自動選択しない。
- 作成済み・未完了・児童ごとの失敗理由を表示する。現在処理中の児童の応答後に停止できる。別画面・職員切替では次の児童への送信を止める。既に送信中の処理を取り消したとは表示しない。
- 同じ職員の履歴直近20件から未完了を再開できる。画面を再読み込みしても同じ操作ID・児童ごとの課題ID・内容で再試行する。保存済み児童には再送しない。他職員への引き継ぎは本単位の対象外。
- 一括指定は追加のみ。一括編集・停止・達成判定は未実装。編集・停止は「児童ごと」で行う。課題は案内であり、未解放ステージの強制解放、他の練習の禁止、コイン・既存進捗・Word承認・正式支援記録の書き換えを行わない。

## 保存・安全性

- Dサポートlesson_task_batchesに作成職員・事業所・不変の課題内容・対象連携revision/校舎/グループ・固定課題UUID・作成結果/日時を保存する。公開応答には氏名・Auth・合言葉・source学習ID・生の学習JSONを含めない。児童名は現在の名簿から表示する。
- 閲覧・実行は作成職員本人、同一事業所、在籍、承認端末、学習連携・課題管理権限で照合する。SQL操作はservice_roleのみ、直接の職員書き込みは許可しない。RLSにより他職員・事業所の操作を隠す。管理者に対する全履歴・引き継ぎ権限の追加は行わない。
- 保存前と結果保存時に現在の児童・連携先・revisionを再確認する。sourceの保存トランザクションでは許可された本人、校舎とグループの確認時スナップショットを再照合する。所属変更・連携解除・許可撤回は未完了のまま停止し、自動的に別児童や新しい所属へ付け替えない。
- sourceの固定課題IDと同一内容再送の仕組みにより、結果応答が失われても重複作成しない。同時再試行も同じ課題・監査1件へ収束する。保存成功の記録を後着の失敗で未完了へ戻さない。
- 両DBをまたぐ全員同時確定や巻き戻しは行わない。一部児童だけ作成済みとなる場合がある。source保存後に連携が変わると、課題は存在してもDサポートの完了記録は未確定になり得る。連携変更後の自動再送はせず個別調査する。
- 「作成済み」は当該課題を作成できた記録であり、後の編集・停止・期間終了を反映した現在の有効状態でも、児童の課題達成でもない。
- 現段階で操作履歴は自動削除しない。UIは直近20件のみ。古い未完了操作の整理・組織の監査保持期間・他職員への引き継ぎは次段階で設計する。

## 展開・検証

- `node scripts/deploy-lesson-task-batches.mjs --apply-and-deploy`: sourceのステージ保存RPC拡張と所属メタデータRPC、Dサポートmigration 202610090003をrollback検証して適用。source support-learning-tasks、Dサポートlesson-task-batchesをデプロイする。既存運用児童・Auth・パスワード・連携許可の更新はしない。
- `check-lesson-task-batches-ui.mjs --cli <Playwright CLI>`: 実Supabaseを遮断した架空画面で絞り込み、表示外の選択も含む確認、未確認の保存禁止、部分失敗、再読込と履歴再開、保存済み除外、職員切替、1280px/390px表示を検証する。既存check-lesson-task-ui.mjsも実行する。
- `check-lesson-task-batches-live.mjs --run-fictional-test`: 本番APIに専用の架空職員・児童を作り、確認のみで未作成、変更された確認内容拒否、部分成功・再開、他職員/RLS/未ログイン拒否、連携・権限変更、source保存後の応答喪失・同時再試行・後着失敗を確認する。試験fixtureを削除し、既存学習JSONのハッシュ不変を確認する。実児童を検証目的で操作しない。
- Dサポート型検査・245テスト・ビルド、Dレッスンcheck:release、両FunctionのDeno型検査、個別課題UI回帰試験を通過。本番DB/Functionの適用と架空児童のAPI検証を実施済み。実児童の公開画面での一括指定試験とは区別する。
- 公開配信は`verify-lesson-task-batches-release.mjs <Dサポート短縮SHA>`で従来の連携機能も含め確認する。Dレッスンの従来管理画面は、本単位の公開をもって廃止しない。
