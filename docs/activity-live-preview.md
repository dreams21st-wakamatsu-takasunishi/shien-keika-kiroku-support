# 活動・指導案の入力とプレビュー

- 幅1,024px以上では、左に仕上がりプレビュー、右に入力欄を表示します。
- 入力欄を選択すると、帳票内の対応箇所を淡い黄色と枠線で強調します。必要な場合はプレビュー内だけがスクロールします。
- プレビューの入力箇所を選ぶと、必要に応じてタブを切り替え、対応する入力欄まで移動してフォーカスします。キーボードでも選べます。
- 活動の流れは追加した行だけをプレビューに表示し、印刷では空の行を出しません。空の案はプレビューから最初の流れを追加できます。
- 「支援項目・種類」は候補選択と自由記入を1欄に統合。「用意するもの」は「内容（概要）」の直後に自由記入でき、従来の準備チェックも利用できます。「実施条件・担当」の先頭に職員人数・児童人数を表示し、保存済みの「対象・人数」は参照用に保持します。
- 長文の入力欄は内容に応じて自動で広がります。端をドラッグして高さを広げる操作にも対応します（対応ブラウザー）。
- 狭い画面では上下表示に切り替えます。プレビューを収納して入力欄を広く使うこともできます。
- 強調表示は印刷されません。印刷・PDF保存は従来のA4帳票です。
- 保存済みの内容や権限は変更しません。プレビューへの反映だけでは保存されません。

## 入力欄が広がり続ける問題への対策

一部の表示倍率で、現在の入力欄の高さと枠線の端数を合算すると、1ピクセルずつ高さが増える現象を再現しました。
内容自体の高さを独立して計測し、サイズ監視は横幅が変わった場合のみ再計測する方式へ変更しています。
空欄の待機・連続入力・長文入力・手動リサイズで高さが安定することを架空データで検証します。

## 検証

- `check-activity-live-preview-ui.mjs`: 架空データで左右表示、項目連動、長文、並べ替え、保存、収納、画面幅、印刷を確認。
- `check-activity-textarea-sizing-ui.mjs`: 表示倍率67～150％での待機・長文・繰り返し入力・手動リサイズ時に、入力欄の高さが安定することを確認。
- `check-input-visuals-ui.mjs`: 入力前後の色分けと既存の編集動線を確認。
- `check-activity-unload-ui.mjs`: 未保存時のブラウザー標準警告と入力保持を確認。
- `activity-live-preview.test.mjs`: 強調先の安定性、HTMLエスケープ、印刷用データ分離を確認。
- `verify-activity-live-preview-release.mjs`: 公開版のバージョン・画面部品・スタイルを確認。実際の業務データにはアクセスしません。
