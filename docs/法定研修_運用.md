# 法定研修の運用

## 職員本人の確認

法定研修ページを開くたびに、現在ログインしている職員名を確認します。「この職員で受講する」を押すまで、研修一覧を取得せず、動画や完了操作も表示しません。違う職員名の場合は「別の職員で受講する（ログアウト）」から本人のアカウントへ切り替えてください。職員を切り替えると再確認が必要です。

完了・取り消しはログインアカウント本人に紐づきます。入力画面で選択した記録者や、外部の企業アカウントには紐づきません。

## 研修の登録

管理者・児発管は「設定 → 法定研修追加」でカテゴリを作成し、そのカテゴリに動画タイトル、動画URL、資料URL（任意）を登録できます。URLはHTTPSのみです。誤登録は非表示にして再登録してください。非表示でも過去の受講履歴は保持されます。

## 受講・取り消し

カテゴリ横の未受講数は、ログイン職員本人の件数です。動画タイトルを押すと動画と資料を別タブで開きます。ブラウザがタブをブロックした場合は「動画を開く」「資料を開く」を個別に押してください。外部サービスには別途ログインが必要です。

受講後に「完了」を押します。誤操作は「取り消し」で戻せます。保存成功後に表示が切り替わり、サーバー時刻で完了を記録します。別端末からの競合が出た場合は再読込して最新状態を確認してください。視聴状況の自動取得は行わず、外部サービスの視聴済み表示と同期しません。これは自己申告の受講記録です。

## 保存と通信

研修名・URLは同じ事業所の職員間で共有するためDサポートのDBに保存します。研修内容をAIへ送信する処理、外部ページの自動取得、埋め込み再生、ローカル保存は追加していません。受講状態は本人のみ取得・更新できます。共通監査ログには研修名・URLを含めません。

## 本番反映

本機能はDB変更と画面の両方が必要です。承認後、`202610060002_legal_training.sql` をDBへ反映し、フロントエンドを公開します。Edge Functionの追加は不要です。公開後は本人確認、管理者・児発管の登録権限、別職員間の受講状態の独立、完了と取り消しの保存を実環境で再確認してください。
