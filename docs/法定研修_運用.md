# 法定研修の運用

## 職員本人の確認

法定研修ページを開くたびに、現在ログインしている職員名を確認します。「この職員で受講する」を押すまで、研修一覧を取得せず、動画や完了操作も表示しません。違う職員名の場合は「別の職員で受講する（ログアウト）」から本人のアカウントへ切り替えてください。職員を切り替えると再確認が必要です。

完了・取り消しはログインアカウント本人に紐づきます。入力画面で選択した記録者や、外部の企業アカウントには紐づきません。

## 研修の登録

管理者・児発管は「設定 → 法定研修追加」でカテゴリを作成し、そのカテゴリに動画タイトル、動画URL、資料URL（任意）を登録できます。URLはHTTPSのみです。

## 表示順・編集・削除

カテゴリと動画の「並び替え」をつかんでドラッグすると、表示順が保存され、職員の受講画面にも反映します。「上へ・下へ」ボタンでも移動できます。キーボードでは並び替えボタンにフォーカスし、スペースで持ち上げ、上下矢印で移動し、スペースで確定します。新しい項目は末尾に追加します。

カテゴリの「研修名を編集」で名前を、各動画の「編集」でタイトル・動画URL・資料URLを変更できます。フォームの保存ボタンで確定します。編集中は表示順の変更を止めています。変更しても既存の受講済み状態は変わらないため、異なる内容の動画への差し替えはせず、新しい動画として登録してください。

「削除」は確認後に一覧から取り除く操作（論理削除）です。カテゴリを削除するとそのカテゴリ内の動画も一覧から消えます。過去の受講履歴は残します。別端末で追加・削除・並べ替え・編集が行われた場合、古い状態からの保存は止めるため、再読込してから操作してください。失敗した編集の入力内容はそのまま残ります。

## 受講・取り消し

### 受講確認フォーム

「設定 → 法定研修追加」の「受講確認フォームURL」に、事業所共通のHTTPSリンクを登録し、「フォームURLを保存」を押します。管理者・児発管が登録・変更できます。空欄で保存すると確認後にリンクを解除します。別端末で変更された場合、古い設定からの上書きを停止し、入力内容は残します。再読込後に「フォームURLの編集をやめる」で最新の登録内容を確認できます。

職員が本人確認を済ませると、法定研修ページの画面下部に「受講確認フォーム」が固定表示されます。スクロール中も押せて、登録先を別タブで開きます。未登録時は押せず、未登録であることを表示します。フォームへの回答や「完了」の状態を自動連携しません。URLの自動取得、AI送信は行わず、共通監査ログにもURLを残しません。

カテゴリ横の未受講数は、ログイン職員本人の件数です。動画タイトルを押すと動画と資料を別タブで開きます。ブラウザがタブをブロックした場合は「動画を開く」「資料を開く」を個別に押してください。外部サービスには別途ログインが必要です。

受講後に「完了」を押します。誤操作は「取り消し」で戻せます。保存成功後に表示が切り替わり、サーバー時刻で完了を記録します。別端末からの競合が出た場合は再読込して最新状態を確認してください。視聴状況の自動取得は行わず、外部サービスの視聴済み表示と同期しません。これは自己申告の受講記録です。

## 保存と通信

研修名・URLは同じ事業所の職員間で共有するためDサポートのDBに保存します。研修内容をAIへ送信する処理、外部ページの自動取得、埋め込み再生、ローカル保存は追加していません。受講状態は本人のみ取得・更新できます。共通監査ログには研修名・URLを含めません。

## 本番反映

本機能はDB変更と画面の両方が必要です。初期機能は `202610060002_legal_training.sql`、表示順と編集機能は `202610060003_legal_training_order.sql`、受講確認フォームは `202610060004_legal_training_confirmation_form.sql` を使用します。承認後に未反映のDB変更を反映し、フロントエンドを公開します。Edge Functionの追加は不要です。公開後は本人確認、管理者・児発管の登録・並べ替え・編集・削除権限、別職員間の受講状態の独立、完了と取り消しの保存、フォームURLの登録と固定ボタンでの表示を実環境で再確認してください。
