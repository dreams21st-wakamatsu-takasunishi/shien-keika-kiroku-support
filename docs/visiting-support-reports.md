# 保育所等訪問支援の報告書

児童名簿 → 「訪問支援報告書」から、対象児童を選択して「新しい報告書」を開きます。保育所等訪問支援を単独で利用する児童と、他サービスと併用する児童が対象です。閲覧・保存には管理者または児発管の権限が必要で、個人端末モードからは開けません。

1. 訪問日・作成日・作成者を確認します。新規作成時は、児童名簿の所属学校・性別・所属（クラス）が、訪問先・性別・所属へ反映されます。訪問日によって異なる場合は報告書側で修正できます。名簿の生年月日は報告書に含めません。
2. 活動ごとに開始時刻、活動内容、子どもの様子、気付いたことを入力します。終了時刻は任意です。必要な分だけ行を追加でき、帳票では開始時刻順になります。
3. まとめ・今後の支援を入力して保存します。再編集は児童を選択し、「保存済みの報告書」から開きます。
4. 広い画面では左のプレビュー、狭い画面では「プレビュー」を使います。帳票の項目を押すと、その入力欄へ移動します。「印刷・PDF」からA4横で印刷・PDF保存できます。

訪問支援報告書は日々の支援経過記録・訪問予定・保管書類の管理情報とは別に保存します。外部AI送信やPDFの外部アップロードは行いません。オフライン保存は行わないため、通信エラー時は画面を閉じずに接続を確認して再保存してください。別の端末から変更済みの場合は自動で上書きしません。

公開には、アプリの反映前に `202611160001_visiting_support_reports.sql` の適用が必要です。この変更に既存データの書き換えは含まれません。
