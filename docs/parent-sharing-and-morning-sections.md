# 保護者への共有文・朝礼の項目別共同編集

2026-11-02。実装・隔離検証・本番公開の確認を分けて記録する。

## 保護者への共有文

- 保存済み支援記録の詳細から開く。支援記録の入力画面は変更しない。
- 定型選択の事実からブラウザー内で下書きを作る。外部AI、LINE自動送信は利用しない。
- 自由記述・特記・詳細学習実績は未選択の要確認候補とする。服薬、安全情報、完了・未完了の不一致は注意を表示する。
- 下書きは元記録と別テーブル、職員ごとに保存する。既存の下書きを開いた際に自動再生成しない。再生成は置換確認を行う。
- コピー前に児童・日付・送信先・本文の確認を求める。毎回サーバーで元記録の版・更新時刻と下書きの版を検証してからコピーする。
- コピーは送信済み扱いにしない。送信先はLINE上でも確認する。下書きの削除は論理削除で、元記録を削除しない。
- RPCは本人・同事業所・通常の記録利用可能端末に限定する。匿名・別事業所・送迎専用個人端末には公開しない。

## 朝礼

- PCは仕上がりプレビューを左、項目別入力を右に表示。小さい画面では入力／プレビューを切り替える。
- 他職員の入力中表示はプレビューと固定高の状況欄で行い、入力欄の上に出し入れしない。
- 本日の予定／欠席・追加利用／送迎確認／児童対応／職員連絡／安全確認／自由記入の7項目。
- 既存本文は変更・分割せず保持し、最初の項目保存時だけ「自由記入・既存の本文」として引き継ぐ。過去履歴は保持する。
- 保存は入力が1.8秒中断した後に項目単位で行う。保存成功後、残りの項目は直列保存する。失敗の自動連打はしない。
- 別項目の保存は独立。同じ項目が変わっていたら双方の文章を表示し、職員が採用内容を選ぶ。自動連結や無条件上書きはしない。
- 保存中の追加入力は残し、直前の保存応答で消さない。旧版応答を新しい状態へ逆流させない。
- リアルタイム送信は既存の事業所・日付限定プライベートチャンネルを継続。項目ごとに未送信内容を保持する。
- 15秒の可視画面再確認、復帰時の再確認、保存通知による再取得を備える。入力内容は通信エラー時もメモリーに保持する。未保存中は日付移動・画面移動・ログアウトを止め、ブラウザー離脱時に警告する。
- 削除通知後は未保存の書き込みを止める。削除前に開始した応答も適用しない。旧画面の全文保存が構造化本文を上書きすることはサーバーで拒否する。
