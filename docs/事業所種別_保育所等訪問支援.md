# 保育所等訪問支援の種別選択

今回の範囲は、事業所種別と児童のサービス選択のみです。訪問先・訪問予定・訪問記録・個別支援計画の新規機能・請求/加算計算は追加していません。

## 事業所の設定（管理者のみ）

「管理者メニュー → 設定 → 職員・運営 → 事業所種別」で、放課後等デイサービス・児童発達支援・保育所等訪問支援を複数選択し保存します。

- 未設定の事業所の種別を推定して登録しません。少なくとも1種類を選んで保存します。
- 自事業所の管理者のみ変更でき、サーバー側の権限・事業所分離を行います。
- 他の管理者の変更と競合した場合は上書きせず、再読込を求めます。操作職員と変更内容は既存の監査ログに記録します。
- 事業所種別を変えても既存の児童、通所予定、記録、送迎は自動で変更しません。児童側の選択肢を隠すこともしません（過去の選択を維持します）。

## 児童名簿

「児童名簿 → 追加/編集 → 事業種別・サービス」で設定します。

- 訪問支援のみ：主なサービスを「保育所等訪問支援」にします。
- 放デイ/児発と併用：主なサービスを放デイまたは児発にし、「保育所等訪問支援も利用する」にチェックします。
- 同じ児童IDを使うため、名簿・学習アカウント・既存記録を二重登録しません。
- 名簿のグリッド/一覧に訪問支援の表示を追加します。「サービス種別」で訪問支援を選ぶと、訪問支援のみと併用の両方を表示します。
- 訪問支援のみの児童は、保存済みの定期利用曜日を通所・送迎の自動反映に使いません。過去の通所曜日・送迎情報・手動登録した既存予定は削除しません。併用児童の通所曜日はこれまで通りです。

DB未反映・権限不足・通信失敗は保存成功として扱いません。ローカル検証は架空データと隔離DBで行い、本番の職員ログイン/端末権限での確認は公開後に別途実施します。
