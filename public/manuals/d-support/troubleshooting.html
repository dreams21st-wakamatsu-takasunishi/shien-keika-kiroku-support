このガイドの使い方

保存できないときも、入力を消す前に確認します。サイトデータ・アプリ・下書きの削除を最初の対処にしません。

2026年10月15日に現行ソース（9f2a811）と説明用画面を照合。画像は架空の児童・職員のデータを使用しています。実在の個人情報・有効なQR・合言葉は掲載していません。

機能の表示・編集可否は役職、追加権限、端末種別、サーバー設定で異なります。画像は操作説明用で、本番の認証・保存テストを示すものではありません。

安全に関わる場合は事業所の緊急連絡手順を優先します。解消しない場合は発生日時・操作・エラー履歴を管理者へ。

記録の保存・入力02 / 22

通信できず記録を保存できない

開く場所：記録作成 → 最終確認

1入力画面を残す
→
2通信の復旧を確認
→
3保存を再試行
  1. 表示されたエラーを確認し、入力内容を控えます。保存ボタンを連打せず、その画面を残します。Wi-Fiに接続済みでもインターネットへ接続できない場合があります。
  2. 他の端末でも通信できるか管理者に確認し、ルーター等の復旧を待ちます。ブラウザーの表示上オンラインでも、サーバー接続を保証するものではありません。
  3. 復旧後、同じ入力画面で保存を再試行します。保存済み内容と照合され、同一なら二重保存せず完了します。保存完了後は一覧で正しい日付・児童の記録を確認します。

注意・相談する目安
保存成功後に応答だけ失われる場合もあります。エラー表示だけで未保存と決めつけず、再試行と一覧で確認します。直らない場合は時刻とエラー履歴を管理者へ。

開く場所：記録作成 → 保存後の案内

1保存済みか確認
→

→
3残りの児童を確認

1使っている端末を特定
→

ログイン・端末・QR08 / 22

開く場所：出退勤・送迎対応 → 本人用QRを表示

1本人・ブラウザーを確認
→
2個人端末を申請・承認
→
3承認状況を再確認
  1. 本人のスマートフォンで自分としてログインし、表示される職員名を確認します。管理者・児発管のメールログインでも、本人用QRの個人端末承認は別に必要です。

ログイン・端末・QR09 / 22

QRが読めない・カメラが起動しない

開く場所：本人用QR表示／施設共用端末のQR読み取り

1カメラとQRの期限
→
2明るさ・反射・距離
→
3成功表示を確認
  1. 施設共用端末の承認・カメラ許可を確認します。他アプリがカメラを使用している場合は終了します。本人用QRは有効期限内・未使用のものを表示します。
  2. 本人端末で「読み取り用に大きく表示」を使い、画面の反射・汚れ・明るさを調整します。近づけすぎず距離と角度を変え、QR全体と白い余白がカメラに入るようにします。
  3. 読み取り後は職員名・出勤／退勤・時刻などの成功表示を確認します。読めない場合にQRのスクリーンショットを他人へ送って代行しません。

注意・相談する目安
眩しく白飛びする場合は明るさを下げ、暗い場合は上げます。単に最大輝度にすればよいとは限りません。端末設定画面の名称は機種により異なります。

→

送迎12 / 22

時間計算が422・502等で失敗する

開く場所：配車編集 → 対象便の時間計算

1編集中の配車を保持
→
2時刻・地点を確認
→
3再試行か管理者へ
  1. 配車を閉じず、便・日付・エラーメッセージを控えます。HTTP番号だけでは原因を特定できません。別の便で成功するかも管理者と確認します。
  2. 出発時刻、乗降順、対象児童の送迎先住所・地点、施設住所など、計算に必要な設定を確認します。422では入力条件、502では外部サービス等を含めた確認が必要な場合があります。
  3. 通信復旧・設定確認後に同じ便で再試行します。解消しなければ管理者がGoogle側のAPI設定・利用制限やサーバー状況を確認します。手動時刻を使うときは根拠と全体の整合を確認して保存します。

注意・相談する目安
計算できたことと、安全で実行可能な送迎であることは別です。根拠のない時刻で確定せず、運転者への連絡を行ってください。

1赤い要対応を先に
→

→

注意・相談する目安
赤＝先に対応、黄＝予定と照合。色だけではなく見出し・説明を確認します。保存した変更は現場にも連絡してください。
