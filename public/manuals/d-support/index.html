このマニュアルについて

2026年10月6日時点のソースと操作画面をもとに作成しました。Dレッスンの要点反映、本人用QRの個人端末登録、法定研修、指導案の入力手順に対応しています。画面が異なる場合は、編集中の内容を保存してからアプリを最新版に更新してください。

画面例には実在の児童・職員の情報を使用していません。事業所の権限、端末種別、連携設定によって使用できる機能が異なります。登録・共有ができたかは、保存完了の表示と保存後の再表示で確認してください。

この冊子は職員向けの主な操作手順です。管理者による導入設定、障害時の技術作業、法令や事業所規程の確認を置き換えるものではありません。

はじめに 01 / 49

ログインと端末の使い分け

開く場所：ログイン画面

1ログイン方法を選ぶ
→
2本人情報を入力
→
3職員名を確認
  1. 職員IDログインでは、事業所コード・職員ID・パスワードを入力します。メール登録のあるアカウントは、メールログインへ切り替えます。
  2. ログイン後、上部の職員名が自分であることを確認します。事業所の共有端末と個人端末では、利用できる画面が異なります。
  3. 本人用QRでログインする場合は、承認済みの事業所端末側で選び、個人端末に表示した本人用QRを読み取ります。

確認ポイント
個人端末の初回ログインは職員IDまたはメールで行います。本人用QRの画像・値は他人へ送らないでください。

ホームで目的の機能を探す

開く場所：ホーム

1目的で絞る
→
2機能を選ぶ
→
3ホームへ戻る
  1. 「ホームの機能を検索」に、欠席・下校・シフト・PDFなどの言葉を入力します。分類ボタンでも目的を絞り込めます。

確認ポイント
メニューが見つからない場合は、検索・分類・非表示設定・アカウントの権限を確認してください。

開く場所：ホーム → 記録作成

1記録日を確認
→
2児童を複数選択
→
3対象を確認
  1. 記録作成を開き、最初に記録日を確認します。当日の利用予定も参照し、対象日を間違えないようにします。

確認ポイント
児童の切り替え前後で、画面の児童名を必ず確認します。記録の内容を別の児童へ流用しないでください。

記録・児童 05 / 49

様子・活動・宿題の記録を入力する

開く場所：記録作成 → 児童を選択 → 項目選択

1項目を開く
→
2観察内容を入力
→
3項目選択へ戻る
  1. 来所時の様子、学習、パソコン、活動など、入力する項目を選びます。選択肢と補足欄を組み合わせて具体的な様子を残します。
  2. 宿題で教科を選んだときは、国語・算数など各教科の詳しい内容も入力します。文章入力練習では、実施した回・文字数を追加します。
  3. 必要に応じてABC分析を入力します。「前の質問」「次の質問」「項目選択へ戻る」で移動し、他児童のタブでも同様に入力します。

確認ポイント
「未回答のみ」や最終確認で不足箇所を確認します。スキップは回答済みとは異なります。観察していない内容を推測で埋めません。

記録・児童 06 / 49

確認して保存・上書きする

開く場所：記録作成 → 最終確認

1未入力を確認
→
2文章を確認
→
3保存結果を確認
  1. 最終確認で未回答・不足している詳しい内容を確認します。不足箇所への移動を使って修正し、生成された文章も読み直します。
  2. 1名だけ完了した場合は「この児童1名分のみ保存」、全員を完了する場合はまとめて保存を使います。
  3. 同じ児童・同じ日の記録があるときは、既存記録と新しい記録のプレビューを比較してから上書きします。保存完了の表示と記録一覧を確認します。

確認ポイント
下書きの保持と保存済み記録は別です。保存に失敗した場合は、入力を残したまま通信・権限を確認してください。

記録・児童 07 / 49

記録状況と記録の引き継ぎ

開く場所：ホーム → 記録状況

1対象日を選ぶ
→
2入力状況を確認
→
3引き継ぎを確定
  1. 対象日を選び、利用予定の児童・入力中の下書き・保存済み記録を確認します。未入力の児童はここから記録を始められます。

確認ポイント
他職員の編集作業と重ならないよう声をかけてください。個人端末では支援記録を入力・引き継ぎできません。

記録・児童 08 / 49

記録一覧で検索・確認・出力する

開く場所：ホーム → 記録一覧・確認

1日付・児童で絞る
→
2記録を確認
→
3コピー・PDF出力
  1. 日付または期間、児童名、状態などで絞り込みます。見出しで並べ替え、必要に応じて並べ替えの優先順を調整します。

一覧の絞り込みは、同じ日の画面往復で維持されます。日付変更・ログアウト後は設定を確認し直してください。外部転記は転記先の児童名も確認します。

記録・児童 09 / 49

クイックメモから申し送りへ登録する

1メモを開く
→
2内容・対象を指定
→
3申し送りへ登録
  1. 黄色いメモアイコンを押して入力欄を開きます。アイコンを移動した場合は、その位置に合わせて入力欄が開きます。

確認ポイント
クイックメモは一時的なメモです。正式な支援記録や継続して共有する情報は、該当機能へ登録してください。

利用・送迎一覧と日ごとの編集

開く場所：ホーム → 利用予定／送迎管理

1対象日を選ぶ
→

予定・送迎 13 / 49

基本予定の反映・一括編集・学校確認

開く場所：利用予定／送迎管理 → 利用予定・送迎の設定

1反映期間を指定
→
2対象・内容を確認
→
3追加・保存
  1. 設定を開き、基本予定の反映開始日・終了日を指定します。児童名簿と学校台帳の長期休暇期間を確認してから反映します。
  2. 「当日一括編集」では、その日の利用児童を続けて編集できます。迎え・送りの時刻、場所、送迎要否、変更メモを確認してまとめて保存します。

確認ポイント
期間を間違えて再反映・一括削除しないよう確認します。長期休暇は所属する学校ごとの登録期間を参照します。

予定・送迎 14 / 49

児童を車両の便へ配車する

開く場所：利用予定／送迎管理で送迎条件を確定 → 配車編集

1迎え／送りを選ぶ
→
2便へドラッグ
→
3配車を保存
  1. 送迎便一覧から配車編集を開きます。迎え・送りを切り替え、各車の1便目を確認します。必要な追加便は「便を追加」で作ります。
  2. 未配車児童のカード全体をドラッグして便に配置します。同じ場所・近い時刻をまとめて移動する設定を使う場合は、対象児童を確認します。
  3. 運転者を指定し、必要なときだけ添乗員欄を開いて追加します。順序・定員・重複を確認し、最後に「配車を保存」を押します。

確認ポイント
編集途中の右側時間表はリアルタイム表示ですが、職員への共有は保存後です。分けて配車する場合はまとめ移動を解除します。

→
2時間を計算
→

確認ポイント
計算は到着を保証するものではありません。通信エラー時は入力を保持し、住所・時刻・Google側設定を管理者に確認します。

Dレッスンの実績を自動反映・再取得する

開く場所：記録作成 → 児童・記録日を選択 → Dレッスンの自動反映

1児童・日付を確認
→
2取得状況を確認
→
3パソコンの内容を確認・保存
  1. 新規の記録では「Dレッスンの実績を自動反映」がオンになります。選択した児童と記録日の練習内容をパソコン欄へ追加します。保存済み記録を編集する場合は初期状態がオフです。
  2. 「取得状況」を開き、児童ごとの件数・未連携・エラー・確認時刻を確認します。続けて練習した実績は「最新の実績を再取得」、1人だけなら「この児童を再取得」で取り直します。
  3. パソコン欄で課題名・完了／途中終了・正確率・文字数を確認し、観察した姿勢・指使い・支援内容を職員が入力します。最終確認から正式な記録を保存し、一覧から開き直して確認します。

確認ポイント
取得時刻は端末時計です。履歴なしを未実施と判断しません。重複は追加せず、元の実績が変更された場合は警告して既存記録を保護します。自動取得は正式保存ではありません。

Dレッスンの要点表示・手入力・実績選択

開く場所：記録作成 → パソコン取り組み内容 → Dレッスン

1要点を確認
→
2不足分だけ手入力
→
3文章・保存を確認
  1. 取り込み実績は初期状態で要点表示です。タイピングは課題名・完了状況・正確率、文章入力は課題名・完了状況・文字数を確認できます。詳細は「取り込んだ実績の詳細」を開きます。
  2. 実績がない練習は「＋ 実績がない取り組みを手入力」で種類・課題名・完了状況・正確率または文字数を入力します。取り込み済みの練習を重ねて選択する必要はありません。
  3. 実績を選んで追加する場合は「実績を選んで追加・再取得」を開き、「実績を全件選択」または個別選択後、児童・日付・内容の確認チェックを入れて追加します。文章は「要点にまとめる」「実績をすべて記載」で切り替えられます。

確認ポイント
全件選択しても確認チェックは省略しません。結果が不明なら空欄・未確認のままにします。表示切り替えで元の実績は消えません。実績の除去では手入力・備考を保持します。
